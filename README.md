Hangman Game 🎮

A simple text-based Hangman Game built using Python. The player guesses a hidden word one letter at a time with limited attempts to win the game.

Features

-> Random word selection

-> Limited incorrect guesses

-> Interactive console gameplay

-> Win/Lose conditions


Concepts Used

- Python Basics
  
- while loops

- if-else statements

- strings and lists

- random module
  

  Developed as part of the CodeAlpha Internship Program.
